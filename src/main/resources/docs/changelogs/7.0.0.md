## Changelog for version 6.4.5 → 7.0.0
- This version requires TaCZ 1.2.0+
- [Feat] Add screen shake system, powered by Ritchie's Projectile Library (bundled via JarJar)
- - Supported trigger time: `on_shoot`, `on_hit`, `on_impact` and `on_explosion` (falls back to `on_impact`)
- - Each trigger time supports power, range, yaw/pitch/roll magnitude, intensity, frequency, drag and translation shake
- [Feat] Add HUD rendering API for animation state machine scripts
- - `gunsmithlib_render_hud(context, gui)`: called after vanilla HUD rendering
- - `gunsmithlib_render_hud_before_hand(context, gui)`: called after world rendering and before hand rendering, with depth test disabled
- - Both hooks only run while holding a scripted gun in the main hand
- [Feat] Add `GuiGraphicsAPI`: pose/style stacks, transforms, scissor, shapes, gradients, lines, text (Style / ChatFormatting), item rendering, blit / nine-slice / repeating textures
- [Feat] Add `InWorldGuiGraphics`: draw HUD anchored to world positions (health bars, lock-on markers, etc.), with optional distance- and FOV-based scaling
- [Feat] Add `gui_graphics()`, `gui_graphics_in_world(world_pos[, scale[, distance_scaled]])` and `world_pos_to_screen_pos(world_pos)` to the animation state machine script extension
- [Feat] Add fire control HUD v2
- - Crosshair now changes color based on IFF: hostile (red), neutral (yellow) and passive (aqua)
- - Animated outer ring, and the target name is shown at long range
- - Configurable per gun with the display property `fire_control_hud_version` (0 = off, 1 = legacy "[+]", 2 = new HUD, default 2)
- [Feat] (WIP) Add bullet control panel to the script API: `control_panel()` provides `create_fragments`, `explode` and `discard` at arbitrary positions, plus `get_context_position()`
- [Feat] Add `charge_progress` papi
- [Feat] Add Gun Metal Block and Giga Shell Block: storage blocks that provides fallback item particles for TaCZ content items. also work as note block instruments, with custom sounds
- [Feat] Add `gunsmithlib.new_vector3`, `gunsmithlib.new_vector3d` and `gunsmithlib.new_style_builder`
- [Feat] Official fire control now works when aiming at blocks (client config `official_fire_control_on_blocks`, plus a configurable drop calibration pass count)
- =============================================================================
- [Fix] Fix TaCZ content items' item particles rendering as black/purple blocks (via the new technical blocks)
- [Fix] Fix ammo variant switching not working on newer TaCZ versions
- [Fix] Fix bullet speed attribute not respecting TaCZ's global bullet speed modifier
- =============================================================================
- [Compat] Update to TaCZ 1.2.0, including its refactored gun HUD, fire select key and animation internals
- [Compat] Remove GunsmithLib's duplicate sound event override, as TaCZ now provides it natively
