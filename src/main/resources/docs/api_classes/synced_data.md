### 简介

这是一个基于 ItemStack NBT 的自动从服务端同步到客户端的同步数据系统。

### 可用版本

自 6.0.0

### API

| 函数名                         | 说明                       | 详细说明                               | 添加版本  |
|-----------------------------|--------------------------|------------------------------------|-------|
| get_int(string)             | **获取**指定 key 对应的同步**整数** | 如指定 key 对应的**整数**不存在则**报错**        | 6.0.0 |
| get_number(string)          | 获取指定 key 对应的同步**实数**     | 如指定 key 对应的**实数**不存在则**报错**        | 6.0.0 |
| get_string(string)          | 获取指定 key 对应的同步**字符串**    | 如指定 key 对应的**字符串**不存在则**报错**       | 6.0.0 |
| optional_get_int(string)    | 获取指定 key 对应的同步**整数**     | 如指定 key 对应的**整数**不存在则**返回 `nil`**  | 6.0.0 |
| optional_get_number(string) | 获取指定 key 对应的同步**实数**     | 如指定 key 对应的**实数**不存在则**返回 `nil`**  | 6.0.0 |
| optional_get_string(string) | 获取指定 key 对应的同步**字符串**    | 如指定 key 对应的**字符串**不存在则**返回 `nil`** | 6.0.0 |
| set_int(string, number)     | **设置**指定 key 对应的同步**整数** | 仅在逻辑脚本（服务端）中可用                     | 6.0.0 |
| set_number(string, number)  | 设置指定 key 对应的同步**实数**     | 仅在逻辑脚本（服务端）中可用                     | 6.0.0 |
| set_string(string, number)  | 设置指定 key 对应的同步**字符串**    | 仅在逻辑脚本（服务端）中可用                     | 6.0.0 |

### 备注

1. 请不要使用 int 类型的方法读写时间戳，否则自 2038 年起你的枪包可能会失效。
